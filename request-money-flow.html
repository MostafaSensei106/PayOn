طلب فلوس — Flow الـ Receiver والـ Sender

📥

Flow of the Receiver

Receiver
1

Create Transaction Draft

Draft
POST CreateTransactionDraft
transactionTypeId = 17 (Request Money)
senderId اللي بطلب منه الفلوس — من Check Wallet
receiverId أنا — my wallet ID
paymentId ❌ شيل من الـ request body
ℹ️ الـ Sender هو اللي بطلب منه، الـ Receiver هو أنا
↓
2

Check Wallet PIN

Verify
POST CheckWalletPin
draftIds من الـ CreateTransactionDraft response
senderId ID اللي بطلب منه الفلوس
accountId my wallet ID
pinHash my pin hash
transactionTypeId = 17
↓
✅

تم إرسال الطلب بنجاح

Request sent successfully screen
